```bash

# 隧道端口 (阿里云, 应只监听 172.18.0.1)
ss -lntp | grep -E ':13306|:12222'
```

## 四、发布与回滚

发布顺序 (canary-first): 飞牛 `.32` → 内网 `.150` → 阿里云。

1. 本地校验: `bash scripts/check-version.sh` + `cd backend && mvn test -Dtest='!*IT,!Integration*Test'` + `cd pc-web && npm run build`。
2. 构建后端: `cd backend && JAVA_HOME=<jdk17> mvn package -DskipTests`。
3. 飞牛: 覆盖 `erp-backend-failover:/opt/app/app.jar` 后重启, 检查 `/tmp/erp-health-feiniu/health.log`。
4. .150: 替换 `backend/industrial-erp-1.0.4.jar` → 重建/重启 `erp-backend`; PC dist 替换 `pc-web/dist` → 重启 `erp-pc-web`; 确保 compose `ERP_VERSION` 与版本一致。
5. 阿里云: 替换 `/opt/app/app.jar` → 重启 `erp-backend`; PC dist 同步; 校验 `http://47.96.188.129/` 与登录。

回滚: 保留上一版 jar 与 dist 目录备份 (部署时命名 `*.bak-<日期>`), 直接换回并重启容器; 数据库脚本均幂等, 回滚代码不需要回滚表结构 (v1.1.129 只新增生成列与唯一键)。

### App (APK) 发布

- App 内嵌 H5 资源 (`dist/build/h5`), 页面改动必须重出 APK; 只更新服务端不会改变已装 App。
- 一键打包: `./scripts/build-app.sh [输出路径]`, 脚本依次执行 H5 构建 → `cap sync android` → `assembleDebug` → 校验 APK 内嵌版本与 OS 级 versionName/versionCode。
- 输出版本默认写到飞牛同步盘 `/Users/tongban/Library/CloudStorage/飞牛同步-Mac/erp/erp-app-YYYYMMDD.apk` 并复制到桌面; 交付前记录 MD5。
- 版本一致性: `app/src/pages/profile/index.vue` 的 `APP_VERSION` = `app/src/manifest.json` 的 `versionName` = `CLAUDE.md` 当前版本; gradle 从 manifest 读取 versionCode, 不接受硬编码。
- 安装: 同签名可直接覆盖安装; 若提示签名冲突先卸载旧版 (卸载会清除 App 本地缓存的服务器地址, 需重新填写)。

## 五、备份与恢复

- 飞牛每天 03:30 备份: `mysqldump | gzip` + `gzip -t` + 表数 ≥100 + `Dump completed` 校验 + SHA256。
- 目录: `/vol1/1000/mac使用/erp/数据备份` (同步到 Mac 飞牛同步盘)。
- 保留: 最近 7 份 + 最近 12 个月每月 1 份。
- 恢复演练 (空库):

```bash
gunzip -c industrial_erp_YYYYMMDD_HHMMSS.sql.gz | \
  docker exec -i erp-mysql sh -c 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" industrial_erp_restore_test'
```

- 恢复生产前先停后端, 避免恢复过程中写入; 恢复后重启并从主库重建两个副本。

## 六、主备切换

正常状态: .150 是唯一可写主库。阿里云临时接管步骤:

```sql
STOP REPLICA;
SET GLOBAL read_only=OFF;
```

然后:

1. 停掉 .150 的业务写入 (停止 `erp-backend` 与 `erp-tunnel`, 防止双写)。
2. 阿里云后端数据源改回 `erp-mysql:3306` (用户 `erp_app`) 并重启。
3. 记录切换时的 binlog 位点; 恢复原主库后, 以切换点做增量对齐再重建复制。

回切: 反向操作, 并从阿里云导出增量应用到 .150, 再重建阿里云只读副本。

## 七、常见故障

| 现象 | 排查 | 处理 |
|---|---|---|
| 公网能读不能写 | 阿里云 `SHOW REPLICA STATUS` IO 线程; 隧道容器 | .150 `docker restart erp-tunnel`; 检查 22 端口与 `authorized_keys` |
| 复制延迟增大 | 备库 `Seconds_Behind_Source`、磁盘 IO | 等待追平; 持续增大查大事务/DDL |
| 备份告警 | `/home/gpssong/erp-backup/backup.log` | 看 mysqldump 错误、磁盘空间、锁目录 |
| 登录后立即 401 | 账号是否被禁用/删除 (v1.1.129 起即时失效) | 管理员确认状态; 正常禁用属预期 |
| 单据号重复 | Redis 是否重启且未开 AOF / 策略是否被改回 allkeys-lru | 保持 `--appendonly yes` + `volatile-lru`; 核对当天最大单号 |
| 库存出现重复行 | 是否执行过 `sql/132` | 执行 `sql/132_v1129_p1_stock_unique.sql` 并检查 `uniq_inv_stock_biz` |
| 磁盘告警 | `df -h`、`docker system df` | 清理旧镜像/日志; 备份保留策略已自动清理 |
