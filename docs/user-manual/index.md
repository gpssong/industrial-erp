## 快速开始

- 登录 (PC / App / H5 浏览器)
- 工作台 / 库存预警解读
- 扫码入库 / 扫码出库
- 销售出库单流程 (草稿 → 审核 → 反审核)

## 各模块速查

| 模块 | 入口 | 核心操作 |
|---|---|---|
| 库存 | 工作台 → 查库存 | 预警列表 / 扫码盘点 |
| 销售 | 销售 → 出库单 | 草稿 / 审核 / 打印 |
| 采购 | 采购 → 入库单 | 收货 / 退仓 |
| 生产 | 生产 → 加工单 | BOM 配方 / 飞鹅云打印 |
| 财务 | 财务 → 应收应付 | 核销 / 开票 |

## 打印 / 分享

- 浏览器打印 (模板设计器)
- 飞鹅云小票打印 (需账号 + UKEY)
- 生产单 PDF 分享 (App 端)

## 常见问题

- 库存预警列表为空?
- 审核按钮灰色?
- App 看不到新功能? (重打包 APK, `scripts/build-app.sh`)
- 登录提示"用户名或密码错误"?
- **销售订单「关联出库单」点「查看」打不开详情 / 弹出空白新增弹窗?**
  - 见 v1.1.50: 出库单号是雪花 ID, 超 2^53 精度上限, 旧版强转 Number 丢精度导致 404。
    已修复 (Delivery.vue 改 String 直传)。清浏览器缓存 / 强刷 (Cmd+Shift+R) 后重试即可。
